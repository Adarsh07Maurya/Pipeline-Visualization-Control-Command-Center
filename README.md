🚀 CodeCommit Pipeline Project

A simple web application where users can upload or commit their code, and an automated CI/CD pipeline handles building, testing, and deployment.

📖 About the Project
This project demonstrates how a CI/CD pipeline works in a real-world development workflow.

When a user commits code:

The code is pushed to the repository.
The pipeline is triggered automatically.
Tests are executed.
The application is built.
The latest version is deployed.
This helps automate software delivery and reduces manual work.

✨ Features
User code submission
Git repository integration
Automatic pipeline execution
Automated testing
Automatic deployment
Build status tracking
Easy-to-use web interface
